# SalemModLoaderInstaller
An easy way to install the Salem Mod Loader for Town of Salem 2.

Only works on Windows at the moment, shell scripts for Mac and Linux are work in progress.

Installation Steps:
- Download the SalemModLoaderInstaller.bat file from here
- Run it, if it's asking you for confirmation click "Run"
- If you play on Steam or Epic, depending on which the script will ask you which platform you want to install the modloader on, reply with either S, E or B
- Once installation is done, launch the game
